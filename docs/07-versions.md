# 07 · Les versions

[← Accueil du dépôt](../README.md) · [Sommaire](README.md)

Les numéros sont ceux de l'appli : date, puis rang.

| Version | Ce qui change | Pourquoi |
|---|---|---|
| `2026-11-05.3` | Tickets par barber, journée, bilan par période, rendez-vous, mise à jour automatique | Remplacer les notes |
| `2026-11-24.1` | Rôles patron et salon, règles d'accès dans la base | L'équipe encaisse sans voir les chiffres |
| `2026-11-25.5` | Annulation sans effacement, réglages du salon, carte et prix modifiables, prix différent pour les réservations en ligne | Ne plus dépendre de moi pour changer un prix |
| `2026-11-25.6` | Compte du jour visible par l'équipe, selon le réglage du patron | Pouvoir vérifier la caisse le soir |
| `2026-11-25.8` | Parts des barbers | Le besoin de départ |

Le numéro de version est choisi avant la mise en ligne : plusieurs versions numérotées `2026-11-25` ont été publiées le 24 au soir.

La `.7` (option « réservation en ligne : oui / non ») est restée sur la base de test.
